# ⚠️ 경고
이 프로그램은 디스코드 Bot을 사용하여 작동합니다.<br>
만약 Bot의 토큰이 변경 될 경우, **파일을 복구 할 수 없습니다.**

추가적으로, 이 봇을 사용하여 발생한 모든 문제는 **사용자에게 책임이 있습니다.**

# 🛠 작동 방식
### 1. 업로드
1. **데이터 압축 및 암호화**: 선택된 업로드 파일을 5MB 단위로 읽고 ZLib 압축을 한 후에, AES-256 방식과 Key는 봇 토큰으로 파일을 암호화 합니다.
2. **텍스트 변환 및 분할**: 암호화 된 파일을 Base64 텍스트로 변환을 하여 .txt 형식의 파일로 변환합니다.
3. **디스코드 전송**: 분할 된 파일을 10개씩 묶어서 저장용 채널에 업로드 합니다. 이 때 메시지를 같이 보내게 되는데, ``(암호화 된 파일 명)_(인덱스)`` 형식으로 메시지가 작성됩니다.
4. **자동 정리**: 작업을 완료 한 후, 로컬에 생성되었던 Temp 파일들을 전부 삭제하여 저장공간을 확보합니다.

### 2. 다운로드 및 복원
1. **목록 동기화**: 리스트 채널의 메시지 내역을 스캔하여 목록을 업데이트 합니다.
2. **파일 검색**: 사용자가 선택한 파일을 저장용 채널에서 찾아, 파일의 순서대로 다운로드 합니다.
3. **복원**: 각 조각을 업로드의 역순으로 하여 원본 파일을 복원합니다.

# 📂 저장 및 관리
 - 설정 및 인덱스: ``%AppData%\Roaming\DiscordCloud`` 폴더 내에 업로드 파일들의 메타 데이터 및 인덱스 정보가 저장됩니다.
 - 암호화: 파일명과 데이터가 모두 봇의 토큰 값으로 암호화 됩니다.
 - 제거: 파일이 제거되었을 경우에, 디스코드의 메시지를 삭제하지 않고, 리스트 채널에 있는 암호화 된 파일 명을 찾아 ``.del`` 을 붙여서 삭제된 파일을 표시합니다. 이를통해 중복 업로드를 방지할 수 있고, 휴지통 기능까지 추가 할 예정입니다.
